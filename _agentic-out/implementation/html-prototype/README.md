# HTML 可交互体验原型

这是一个零依赖、设备本地、确定性模拟的体验原型。它用于验证浏览、判断、规则校准与故障恢复，不是原生 MVP，不会访问真实来源、AI、通知、托盘或其他原生 API，也不会持久保存真实数据。

## 启动

直接用现代浏览器打开 `index.html`。无需安装依赖或启动服务器；所有数据均写在 `app.js` 中，不产生网络请求。

自动检查：

```powershell
node --check _agentic-out/implementation/html-prototype/app.js
node _agentic-out/implementation/html-prototype/prototype-smoke.mjs
```

## 建议验收路径

### 桌面（建议 1280×800 或更宽）

1. 在“主情报流”输入搜索词，组合重要度与赛道条件；逐个移除条件并使用“恢复默认”。
2. 选择不同情报，展开“评分依据、原始事实与完整溯源”；确认搜索和筛选未清空。
3. 收藏、加入待研究、提交反馈，再使用底部提示的“撤销”；确认详情不跳离。
4. 点击“查看模拟原文”，用 `Tab` 检查焦点循环，用 `Esc` 关闭并确认焦点返回触发按钮。
5. 使用 `J/K` 或方向键移动选择，`Enter` 进入详情，`S` 收藏，`F` 反馈，`O` 查看模拟原文，`/` 聚焦搜索。
6. 进入“雷达规则”：清空关键词验证阻断错误；制造关注/排除词冲突；把阈值调到 89 以上并确认风险；分别验证保存成功和模拟失败保留输入。
7. 进入“同步与诊断”：切换离线、部分成功、限流、AI 等待；确认缓存/影响范围/数据安全说明；重试后确认恢复计数增加且重复副作用仍为 0。

### 手机（开发者工具设为约 390px 宽）

1. 保留一组搜索和筛选条件，选择条目进入单栈详情。
2. 展开证据、收藏并反馈，点击“返回情报流”；确认筛选、选择和动作结果仍在。
3. 再次进入详情并按 `Esc`（外接键盘路径）返回；检查底部导航与核心触控目标。
4. 在三个一级目的地间切换，确认无阻断性横向滚动；规则未提交输入在布局变化后仍保留。

## 状态与边界

- 首次加载、局部同步、空结果、成功、字段错误、保存失败、离线、部分成功、限流和 AI 等待均有可见演示入口。
- 状态通过文字、边界和语义共同表达，不只依赖颜色；支持 `prefers-reduced-motion` 与强制颜色模式。
- `#item/<标识>` 可模拟深链；未知标识显示“目标不可用”并提供安全回退，不触发任何副作用。
- 页面刷新会重置收藏、反馈、规则和故障场景，这是原型的刻意边界。
- 自动检查只验证静态契约与 JavaScript 语法，不能替代 NVDA、VoiceOver、TalkBack、真实设备或原生应用的运行时无障碍验收。
