# Story 1.7：浏览可访问的演示情报列表与证据详情

状态：review

## Story

作为首次使用者，  
我希望在 Windows 原生界面中浏览演示情报并查看清晰、可访问的证据详情，  
以便理解产品如何把信息转化为可核验判断。

## 验收标准

### AC1：稳定的 Windows 列表—详情浏览

**Given** 演示情报已经加载  
**When** 用户通过鼠标或键盘选择一条列表记录  
**Then** Windows 在宽布局中原位更新详情，在空间不足时进入独立详情视图或 Sheet  
**And** 当前选择、列表焦点、搜索/筛选条件及列表滚动锚点保持稳定；切换记录只将详情回到顶部，不滚动列表。（FR2、UX-DR2、UX-DR11、UX-DR12）

### AC2：从判断到证据的固定信息层级

**Given** 用户打开演示情报详情  
**When** 首个详情视口完成渲染  
**Then** 按“来源与标题、发生了什么、为什么重要、可能影响、重要程度、AI 置信度、主要操作”的顺序展示  
**And** 原始事实、规则判断、示例 AI 内容和溯源分别使用语义标题/region 与“演示数据”“AI 生成”等文字或图标标识，不只依赖颜色；缺失字段显示“未提供”。（UX-DR3、UX-DR4、NFR29）

### AC3：Windows 设计系统与自适应布局

**Given** Windows 已实现列表与详情  
**When** 检查视觉和响应式实现  
**Then** 使用现有 React、shadcn/ui、Tailwind CSS 与适用的 Radix 原语，页面不是 Card 墙  
**And** 颜色、字体、间距、边框、焦点、运动和反馈均引用 `DESIGN.md` 语义 token，不在页面硬编码视觉值；1024×700 最小窗口及适用窄宽度下核心内容和操作仍可达。（UX-DR1、UX-DR22）

### AC4：Windows 键盘与稳定自动化语义可用

**Given** 用户仅使用键盘  
**When** 选择条目、进入详情、遍历事实/规则/AI/溯源区块并返回列表  
**Then** 核心操作具有稳定的可访问名称、角色、状态、可见焦点和与视觉一致的遍历顺序  
**And** 上/下方向键及 J/K 移动选择，Enter 将焦点进入详情，Esc 返回已选列表项，`/` 聚焦搜索；输入控件内不截获快捷键，无焦点陷阱，所有快捷操作均有可见等价入口。（UX-DR20、UX-DR21、UX-DR24、NFR30 scoped evidence）

当前产品不承诺盲人屏幕阅读器支持；稳定名称、角色、状态与顺序继续作为 UI Automation、自动化定位和一致交互的工程合同。

### AC5：主题、缩放和关键状态可复现

**Given** 组件处于浅色/深色主题及 default、focus、selected、loading、empty、error/retry 状态  
**When** 执行 Windows 场景和真实候选构建检查  
**Then** `IntelligenceFeedItem`、`EvidenceDetailPanel` 与 `SourceProvenanceGroup` 的关键状态均可稳定复现  
**And** 开发阶段的等效视口、主题场景、forced-colors/Reduce Motion、UIA 和默认环境候选 smoke 中，阻断阅读/操作的裁切与重叠为 0；100%、125%、150%、175%、200% × 浅/深主题的真实系统矩阵移交专用发布测试机或隔离虚拟机，不要求修改开发者日常系统设置；HTML 原型、截图或组件测试不冒充候选运行证据。（UX-DR19、UX-DR21、UX-DR23、NFR31 scoped evidence）

## Dev Notes

### 强制数据流

```text
contracts/fixtures/demo（唯一证据事实）
  → radar-core validation / SQLite / Application queries
  → approved Tauri commands
  → DesktopApi runtime guards
  → TanStack Query
  → Windows presentation models
  → IntelligenceFeedItem / EvidenceDetailPanel / SourceProvenanceGroup
```

### 实现护栏

- 先扩展共享证据合同，再做 UI；UI 不推断 ID、不重新计算重要度/置信度，也不生成事实、规则或 AI 文本。
- 继续使用 `View → Provider → DesktopApi → Tauri command → radar-core`；只有 `tauri-desktop-api.ts` 可调用 `invoke`，React/Tauri 不访问 SQLite。
- 当前 demo feature、fixture、SQLite/FTS、commands、guards、query client、Playwright fixture 与零外联探针均须复用。新增 command 必须精确加入 release allowlist；不要引入通用 execute、shell/fs/http 权限。
- WAI-ARIA listbox 的 option 是扁平名称模型且不适合包含可交互后代；开发者必须按实际条目结构选择原生 list/button 或真正合规的 listbox，不能只换 role。
