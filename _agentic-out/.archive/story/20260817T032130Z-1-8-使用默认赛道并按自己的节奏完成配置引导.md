# Story 1.8：使用默认赛道并按自己的节奏完成配置引导

状态：review

## Story

作为首次使用者，  
我希望立即使用预置 AI 技术赛道，并可跳过或稍后恢复配置引导，  
以便先体验产品，再按自己的节奏进行个性化。

## 验收标准

### AC1：默认赛道和来源示例立即可用

**Given** 当前设备尚无用户配置  
**When** 用户首次进入主情报流  
**Then** 系统提供清晰命名的默认 AI 技术赛道和默认来源示例  
**And** 默认项与演示数据的关系可理解，明确标注“示例/演示”，不暗示已经执行真实同步。（FR3）

### AC2：引导可跳过且不阻断核心旅程

**Given** 引导邀请用户配置赛道、来源、刷新周期或查看 AI 数据说明  
**When** 用户选择“跳过”或“稍后继续”  
**Then** 用户立即返回可浏览的主情报流，且搜索、筛选和详情不被引导阻断  
**And** 已保存的步骤配置不得丢失；跳过只改变引导进度，不删除配置。（FR1、FR61、UX-DR7、NFR33）

> Story 2 才提供真实同步；本 AC 中“同步不被阻断”表示引导不能成为未来同步入口的前置门，本 Story 不伪造同步能力。

### AC3：设置根页固定入口可恢复

**Given** 用户从主情报流准备恢复引导  
**When** 导航到设置根级页面  
**Then** 页面提供名称固定为“配置引导”的可见入口并显示当前进度  
**And** Windows 路径固定为“主情报流 → 设置 → 配置引导”，从主情报流不超过两次用户导航；入口不藏在搜索、Tooltip、帮助或深层子页面。（FR61、NFR33、UX-DR27）

### AC4：完成、跳过和中断后正确恢复

**Given** 用户完成、跳过或中断某个引导步骤  
**When** 应用退出、重启或重新进入 `/settings/setup`  
**Then** 系统恢复到首个适用的未完成步骤，并保留此前已保存的配置  
**And** 已完成步骤不强制重播；不得因缺少注册、云账户、AI Key 或通知授权而反复强迫用户。（FR1、FR61、NFR28、NFR33、ARCH-29）

### AC5：键盘与非颜色状态表达

**Given** 用户仅使用键盘访问配置引导  
**When** 焦点到达入口或引导操作  
**Then** 入口具有稳定名称“配置引导，{当前状态}”，跳过、稍后继续、返回和保存均可操作，关闭后焦点返回触发项  
**And** 进度使用可见文字/图标表达，不仅依赖颜色或进度图形；无焦点陷阱。（UX-DR20、UX-DR27）

### AC6：当前设备边界说明清晰但不制造警报

**Given** 首启界面需要说明数据作用域  
**When** 用户查看首次使用说明或默认配置  
**Then** `DeviceScopeNotice` 明确说明配置和演示体验仅影响此 Windows 设备，MVP 无云备份或跨设备同步  
**And** 使用常规信息层级，不伪装为错误或破坏性警告，不读取硬件标识或申请额外权限。（UX-DR9）

### AC7：Windows Epic 1 首次体验闭环

**Given** Story 1.1、1.2、1.6、1.7、1.8 的 Windows 范围完成  
**When** 在当前 Windows 候选构建执行 Epic 1 首次体验  
**Then** 用户可完成启动、演示浏览、基础筛选、详情查看、跳过和恢复引导  
**And** 不依赖真实来源、AI 分析或通知即可提供价值。（FR1–FR3、FR61、NFR28、NFR33、NFR39 scoped）

Apple/iPhone/iPad/Android 原 AC7 运行证据继续为 Deferred Acceptance；本 Story 不标记跨平台 MVP PASS。真实 Windows 5 个缩放档 × 2 个主题系统矩阵继续移交专用发布环境。

## Dev Notes

### 强制数据流

```text
contracts/fixtures/setup/defaults-v1.json
→ radar-core DTO/domain validation
→ single SQLite owner (settings_metadata + setup_progress)
→ get_setup_progress/save_setup_step
→ exact Tauri commands
→ DesktopApi guards
→ TanStack Query
→ /settings and /settings/setup
→ ProgressiveSetupGuide
```

- Core 是默认值、进度、next-step 和已保存字段版本的唯一事实源；React 只渲染并发送用户 intent。
- `save_setup_step` 的业务字段与进度必须在同一事务提交；不得出现“进度已完成但配置未保存”。
- 默认赛道与 Story 1.6 demo fixture 可有关联说明，但不要复制 demo fixture 或让 UI 根据标题推断业务默认值。
- Story 1.1/1.2 的 AppError、opaque ID、RFC3339 UTC、panic containment 和边界扫描继续适用。

### 技术与依赖

- 保持当前锁定：Rust 1.97.1、Tauri 2.11.5、CLI 2.11.4、React 19.2.8、TypeScript 5.9.3、Vite 8.2.1、TanStack Query 5.101.4、Tailwind 4.3.3、rusqlite 0.40.1 bundled、SQLite 3.53.4。
- 新增且精确锁定 `react-router` `8.3.0`。官方 Declarative Mode 使用 `react-router` 包和 `<BrowserRouter>`；本地数据仍由 TanStack Query 管理。[React Router official installation](https://reactrouter.com/start/declarative/installation)
- 所有依赖和浏览器缓存必须留在 `.toolchains/`、项目 store/cache 或项目 `node_modules`；禁止全局安装，也不得影响全局 Python。
